### 1. Directory Navigation and Management

- `pwd` — Display the current working directory.
- `ls` — List files and directories.
- `cd` — Change the current directory.
- `cd ..` — Move to the parent directory.
- `mkdir` — Create a directory.
- `rmdir` — Remove an empty directory.

### 2. File Operations

- `touch` — Create an empty file.
- `echo` — Display or write text.
- `cat` — Display file contents.
- `cp` — Copy a file.
- `mv` — Rename or move a file.
- `rm` — Remove a file.
- `head` — Display the first lines of a file.
- `tail` — Display the last lines of a file.

### 3. Searching and Text Processing

- `find` — Search for files and directories.
- `grep` — Search for matching text.
- `wc` — Count lines, words, and bytes.
- `sort` — Sort lines of text.

### 4. System and Terminal Utilities

- `clear` — Clear the terminal display.
- `history` — Display previously executed commands.
- `du -h` — Display disk usage in a readable format.
- `date` — Display the system date and time.

### 5. File Redirection

- `>` — Write output to a file, replacing existing content.
- `>>` — Append output to a file without replacing existing content.
